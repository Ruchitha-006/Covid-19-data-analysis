# COVID-19 Data Analysis

## 📌 Project Overview
This project performs a beginner-friendly data analysis on global COVID-19 data to understand how the pandemic evolved over time across different countries. The analysis focuses on trends in cases, country-wise comparison, and death rate calculation using Python.

The goal of this project is to practice real-world data handling, cleaning, and visualization using a large CSV dataset.

## 🎯 Objectives
- Analyze COVID-19 case trends over time
- Compare total cases across multiple countries
- Calculate and analyze COVID-19 death rates
- Practice data cleaning and transformation using Pandas
- Create clear and simple visualizations

---

## 📂 Dataset
- **Source:** WHO COVID-19 Global Data
- **Format:** CSV
- **Size:** 100,000+ rows
- **Type:** Raw, real-world dataset

> The dataset was used in its raw form and cleaned inside the notebook for analysis.
